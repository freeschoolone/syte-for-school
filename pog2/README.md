# Образовательный портал «Искусственный интеллект в жизни школы»
**МБОУ «Гимназия № 1 имени А. Н. Барсукова» города Коврова**  
*Индивидуальный проект (10 класс, 2026 г.)*

## Структура многостраничного сайта
В проект входят 7 файлов, полностью готовых к выгрузке на **GitHub Pages** или любой хостинг:

1. `index.html` — Главная страница (паспорт индивидуального проекта, статистика опроса старшеклассников, навигатор).
2. `gymnasium.html` — О Гимназии № 1 г. Коврова (историческая справка об А. Н. Барсукове, официальные реквизиты, адрес: г. Ковров, ул. Абельмана, д. 15, профильные направления).
3. `catalog.html` — Интерактивный каталог нейросетей по школьным предметам с фильтрацией (физика, алгебра, литература, информатика, биология, английский язык).
4. `teachers.html` — Кафедры и педагоги (методические объединения гимназии с фотографиями и принципами академической честности).
5. `practice.html` — Промпт-лаборатория (интерактивный конструктор учебных промптов + блиц-тест из 4 вопросов с подсчётом баллов).
6. `styles.css` — Единая таблица стилей (адаптивная тёмная тема, карточки, сетки).
7. `script.js` — Клиентская логика (фильтрация карточек, генератор промптов, копирование в буфер обмена и проверка теста).

## Как выложить многостраничный сайт на GitHub Pages за 2 минуты
1. Создайте новый публичный репозиторий на [github.com](https://github.com/) (например, `kovrov-gymnasium1-ai`).
2. Нажмите **Add file → Upload files** и перетащите **все файлы из архива** (`index.html`, `gymnasium.html`, `catalog.html`, `teachers.html`, `practice.html`, `styles.css`, `script.js`) в корень репозитория.
3. Нажмите зелёную кнопку **Commit changes**.
4. Перейдите в **Settings → Pages**, в разделе **Branch** выберите `main` и нажмите **Save**.
5. Через 1–2 минуты ваш многостраничный сайт будет доступен по ссылке `https://ваш-логин.github.io/kovrov-gymnasium1-ai/`.
