9 практических решений

Каталог ИИ-инструментов по предметам

Не список сервисов для готовых ответов, а методическая карта: какая технология подходит задаче, как построить работу и что обязательно проверить самостоятельно.

Фильтрация работает без перезагрузки страницы
Учебные сценарии

Выберите предметное направление

Один инструмент может относиться сразу к нескольким направлениям. Фильтры помогают быстро собрать свой набор для профильной подготовки.

Показано инструментов: 9 из 9

01
  • Точные науки

Gemini 2.5 Pro / ChatGPT o3

Пошаговый тьютор по кинематике, динамике и математическому анализу.

Методика
Попросить не решать задачу сразу, а сначала определить известные величины, закон и план из 3–5 шагов.
Самопроверка
Сверить единицы измерения, знаки, область допустимых значений и ответ по учебнику или собственной подстановкой.
Не использовать
Для переноса полного решения в работу без понимания каждого преобразования.
  • Кинематика
  • Динамика
  • Матанализ
02
  • Вычисления

WolframAlpha & Desmos AI

Символьная алгебра, графики с параметром №18 ЕГЭ и вычисления в астрофизике.

Методика
Сначала получить собственную гипотезу о числе решений, затем менять параметр на графике и фиксировать критические значения.
Самопроверка
Подтвердить найденные границы аналитически: через дискриминант, касание, монотонность или систему уравнений.
Не использовать
Как замену выводу формулы и доказательству переходов.
  • Алгебра
  • №18 ЕГЭ
  • Астрофизика
03
  • Работа с источником

NotebookLM

Анализ строго по загруженным текстам классических произведений без выдумывания цитат.

Методика
Загрузить текст «Грозы», «Горя от ума» или «Евгения Онегина», задать вопрос о конфликте и попросить указать место в источнике.
Самопроверка
Открыть исходный фрагмент, проверить точность цитаты и объяснить её роль собственными словами.
Не использовать
Для сочинения, где позиция и аргументация должны принадлежать ученику.
  • Островский
  • Грибоедов
  • Пушкин
04
  • Программирование

GitHub Copilot & Cursor IDE

Отладка кода на Python и C++, разбор алгоритмов и задач КЕГЭ по информатике.

Методика
Передать минимальный пример ошибки и попросить объяснить причину, предложить тесты и подсказку без готового финального кода.
Самопроверка
Запустить граничные тесты, оценить сложность алгоритма и самостоятельно переписать исправление.
Не использовать
Для вставки непонятого кода и передачи закрытых данных в облачный сервис.
  • Python
  • C++
  • КЕГЭ
05
  • Английский язык

DeepL Write & ELSA Speak AI

Тренажёр письменного эссе и устной части ЕГЭ по английскому языку.

Методика
Сначала написать собственный текст или записать речь, затем запросить объяснение 3 главных ошибок и упражнение на каждую.
Самопроверка
Сохранить первоначальный вариант, сравнить правки и проговорить исправленные фразы без подсказки.
Не использовать
Для полной автоматической переписи эссе перед сдачей.
  • Эссе
  • Произношение
  • ЕГЭ
06
  • Исследование

Perplexity AI Academic

Поиск проверяемых научных источников для индивидуальных проектов 10 класса.

Методика
Сформулировать исследовательский вопрос, ограничить период и попросить первичные источники с авторами, датой и ссылкой.
Самопроверка
Открыть каждый источник, проверить соответствие утверждения оригиналу и оформить библиографию по требованиям руководителя.
Не использовать
Для цитирования пересказа ИИ вместо прочитанной публикации.
  • Источники
  • Фактчекинг
  • Проект
07
  • 3D-модели

AlphaFold Server & MolView

Трёхмерная визуализация белков и молекул на профильной биологии и химии.

Методика
Сравнить предсказанную структуру с учебной схемой, выделить функциональные участки и сформулировать ограничения модели.
Самопроверка
Проверить легенду, химическую формулу, типы связей и показатель уверенности предсказания.
Не использовать
Как доказанный экспериментальный результат без проверки научной публикацией.
  • Белки
  • Молекулы
  • Структура
08
  • Стереометрия

GeoGebra 3D + AI

Построение сечений многогранников и проверка пространственных гипотез.

Методика
Сначала выполнить чертёж от руки, затем построить модель по заданным точкам и исследовать положение плоскости при вращении.
Самопроверка
Обосновать каждую линию сечения принадлежностью одной грани и проверить замкнутость многоугольника.
Не использовать
Для подмены геометрического доказательства красивой визуализацией.
  • Сечения
  • Многогранники
  • Модель
09
  • Защита проекта

Gamma App

Оформление презентаций и инфографики для защиты индивидуальных проектов.

Методика
Передать собственный проверенный план и данные, ограничить число слайдов и попросить по одному тезису на экран.
Самопроверка
Удалить вымышленные факты, проверить числа, источники, авторские права на изображения и единообразие терминов.
Не использовать
Для автоматической генерации содержания проекта, которое автор не может защитить устно.
  • Презентация
  • Инфографика
  • Выступление
!
Общее правило. Перед использованием сервиса проверьте его возрастные ограничения и политику данных. Не передавайте персональные данные, пароли, закрытые документы гимназии или неопубликованные работы других людей.
