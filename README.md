# ФактЧек — тренажёр медиаграмотности

Автономный интерактивный веб‑тренажёр, который помогает проверять интернет‑публикации по методу **«ФАКТ»**:

- **Ф** — сформулируй проверяемое утверждение;
- **А** — анализируй автора и первоисточник;
- **К** — проверь контекст, дату и доказательства;
- **Т** — требуй подтверждения из независимых источников.

## Возможности

- 8 смоделированных интернет‑публикаций;
- 24 интерактивные улики;
- выбор вердикта и подробная обратная связь;
- система баллов и четыре итоговых уровня;
- сохранение лучшего результата в браузере;
- адаптивная версия для компьютера и телефона;
- печатная памятка «ФАКТ»;
- работа без внешних библиотек и регистрации.

## Запуск на компьютере

Откройте файл `index.html` в браузере.

## Публикация на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `factcheck-trainer`.
2. Загрузите **содержимое этой папки** в корень репозитория. Файл `index.html` должен находиться в корне, а не во вложенной папке.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`;
   - Branch: `main`;
   - Folder: `/ (root)`.
5. Нажмите **Save**.
6. После публикации сайт будет доступен по адресу вида:
   `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/factcheck-trainer/`.
